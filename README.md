# FORGE

Welcome to **FORGE**, a comprehensive app to track your workouts, manage your tasks, and stay on top of your projects.

## Features
- **Gym**: Track your workouts, generate AI-powered routines, and monitor your personal records.
- **Projects & Tasks**: Stay productive and keep track of your daily tasks.
- **Insights & Logs**: View your progress with detailed charts and logs.

## Download the App

You can download and install the latest Android APK (EAS Build) for FORGE.

**How to install the APK:**
1. Download the `.apk` file to your Android device (you can find it in the GitHub Releases if uploaded, or ask the developer for the EAS build link).
2. Open the downloaded file.
3. If prompted, allow "Install from unknown sources" in your device settings.
4. Follow the on-screen instructions to complete the installation and launch FORGE!

## Local Development Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npx expo start
   ```

## Tech Stack
Built with [Expo](https://expo.dev) and React Native.
